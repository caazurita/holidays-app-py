[![Python](https://img.shields.io/badge/python-3.12+-blue.svg)](https://www.python.org/downloads/)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A FastAPI-powered REST API that fetches public holidays worldwide, enriches them with AI-generated summaries and categories — **national**, **cultural**, and **religious** — and caches results in Redis for performance.

---

## Features

- **Global holiday data** — sourced from the [Nager.Date](https://date.nager.at/) public API.
- **AI enrichment** — each holiday gets a concise 2-sentence summary and a category classification via Google Gemini.
- **Flexible time filters** — filter holidays by current week, next week, current month, or next month.
- **Redis caching** — AI-generated summaries are cached for 24 hours to reduce latency and API costs.
- **Asynchronous architecture** — built on FastAPI and `httpx` for non-blocking I/O.

## Architecture

```
┌─────────────┐     ┌──────────────┐     ┌───────────────┐
│   Client    │────▶│  FastAPI     │────▶│  Nager.Date   │
│  (cURL/Web) │     │  /holidays/* │     │  Public API   │
└─────────────┘     └──────┬───────┘     └───────────────┘
                           │
                    ┌──────▼───────┐
                    │  Redis Cache │
                    │  (24h TTL)   │
                    └──────┬───────┘
                           │
                    ┌──────▼───────┐
                    │  Google      │
                    │  Gemini      │
                    │  (AI summary │
                    │   + category)│
                    └──────────────┘
```

1. A client requests holidays for a given country and time filter.
2. The service fetches raw public holiday data from Nager.Date.
3. Before calling the AI, it checks Redis for cached summaries.
4. Missing summaries are generated by Google Gemini, then cached.
5. The enriched response is returned to the client.

## Getting Started

### Prerequisites

- Python 3.12+
- A [Redis](https://redis.io/) instance (local or cloud, e.g. Redis Cloud)
- A [Google AI API key](https://ai.google.dev/gemini-api/docs/api-key)

### Installation

```bash
git clone https://github.com/your-username/holiday-app.git
cd holiday-app
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

### Environment Variables

Create a `.env` file in the project root:

```env
GOOGLE_API_KEY=your_google_gemini_api_key

REDIS_HOST=your-redis-host
REDIS_PORT=your-redis-port
REDIS_USERNAME=default
REDIS_PASSWORD=your-redis-password
```

> **Security:** Never commit your `.env` file. The project's `.gitignore` already excludes it.

### Run the Server

```bash
fastapi dev app/main.py
```

The API will be available at `http://localhost:8000`.

Interactive docs: `http://localhost:8000/docs`

## API Reference

### `GET /`

Returns a welcome message.

**Response:**
```json
{
  "message": "Welcome to the Holiday API. Use /holidays/next-holidays to fetch upcoming holidays."
}
```

### `GET /holidays/next-holidays`

Fetch upcoming holidays for a country, enriched with AI-generated summaries and categories.

**Query Parameters:**

| Parameter | Type   | Required | Description                                        |
| --------- | ------ | -------- | -------------------------------------------------- |
| `country` | `str`  | Yes      | ISO 3166-1 alpha-2 country code (e.g. `US`, `MX`) |
| `filter`  | `enum` | Yes      | Time window filter (see values below)              |

**Filter values:**

| Value            | Description                             |
| ---------------- | --------------------------------------- |
| `current-week`   | Holidays from today through the week    |
| `next-week`      | Holidays from today through next 7 days |
| `current-month`  | Holidays in the current calendar month  |
| `next-month`     | Holidays in the next calendar month     |

**Example Request:**
```bash
curl "http://localhost:8000/holidays/next-holidays?country=MX&filter=current-month"
```

**Example Response:**
```json
{
  "succes": true,
  "body": [
    {
      "local_name": "Día de la Independencia",
      "date": "2025-09-16",
      "country_code": "MX",
      "type": "Public",
      "summary": "Mexican Independence Day celebrates the start of the war for independence from Spain in 1810. It is marked with parades, fireworks, and traditional food.",
      "category": "national"
    }
  ]
}
```

> Note: The `type` field comes directly from the Nager.Date API and represents the public holiday type.

## How It Works

### Holiday Categorization

All categorization is performed by **Google Gemini**. The prompt instructs the model to classify each holiday as one of:

- **`national`** — Independence days, flag days, national celebrations
- **`cultural`** — Festivals, traditions, local observances
- **`religious`** — Christmas, Easter, Ramadan, Diwali, etc.

Each holiday also receives a **2-sentence summary** explaining its significance.

### Caching Strategy

- **Key format:** `holiday:{country}:{localName}`
- **TTL:** 86,400 seconds (24 hours)
- On a request, uncached holidays are batched and sent to Gemini together, then stored individually in Redis.
- Subsequent requests for the same country and holiday return instantly from cache.
